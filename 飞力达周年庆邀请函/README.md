# 飞力达十周年庆典H5邀请函

## 项目概述

这是一个为飞力达公司十周年庆典设计的H5邀请函页面，以"用户陪伴品牌成长"为主题，通过精美的视觉设计和丰富的交互效果，展示品牌发展历程和用户故事。

## 项目结构

```
飞力达周年庆邀请函/
├── index.html          # 主页面文件
├── css/
│   └── style.css       # 样式文件
├── js/
│   └── script.js       # JavaScript交互逻辑
└── README.md           # 说明文档
```

## 页面设计

### 第1页：首页
- 品牌Logo和标语展示
- 十周年庆典主题
- 邀请函信息（日期、地点）
- 动态效果和装饰元素

### 第2页：品牌发展历程
- 时间轴展示2014-2024年关键节点
- 品牌诞生、服务升级、全国布局等重要事件
- 左右交错的时间轴设计
- 渐入动画效果

### 第3页：品牌故事
- 初心不改：展示品牌理念
- 全球网络：展示服务范围
- 卡片式布局，每张卡片包含图片

### 第4页：用户故事
- 真实用户案例展示
- 用户头像、 testimonial 文案
- 关键数据指标展示
- 可切换的用户故事轮播

### 第5页：互动页
- 庆典预约表单（姓名、电话、公司、祝福语）
- 倒计时显示
- 提交成功反馈

## 交互功能

1. **滑动翻页**
   - 触摸屏：向上/向下滑动
   - 鼠标：滚轮滚动
   - 键盘：方向键上下

2. **导航点**
   - 右侧导航点指示当前页面位置
   - 点击导航点直接跳转到对应页面

3. **用户故事切换**
   - 点击导航圆点切换不同用户故事
   - 平滑过渡动画效果

4. **表单交互**
   - 输入框焦点效果
   - 提交成功反馈弹窗

5. **动画效果**
   - 页面入场动画
   - 元素渐显效果
   - 装饰元素浮动动画

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 在移动设备上查看效果更佳
3. 可以在本地服务器上运行

## 技术特点

- **响应式设计**：适配各种移动设备屏幕
- **纯HTML/CSS/JavaScript**：无需依赖第三方库
- **平滑动画**：CSS3动画和JavaScript控制的过渡效果
- **渐变色彩**：使用现代渐变色设计
- **移动端优化**：专门针对移动设备优化的交互体验

## 自定义修改

### 修改庆典日期
在 `js/script.js` 中找到：
```javascript
const eventDate = new Date('2024-06-18T00:00:00');
```
修改为您需要的日期。

### 修改品牌信息
在 `index.html` 中直接修改Logo、标语等文本内容。

### 更换图片
替换以下图片URL为您自己的图片：
```html
<img src="您的图片URL" alt="描述">
```
